# Gizli Sayıyı Tahmin Et (Guess the Secret Number)

Bu proje, Python'da **`while` döngüsü** mantığını kavramak amacıyla hazırlanmış basit bir sayı tahmin oyunudur. Kullanıcı, önceden belirlenmiş gizli sayıyı (`777`) doğru tahmin edene kadar döngü içinde kalır.

## Kullanılan Kavramlar

* **`while` Döngüsü:** Koşul sağlandığı sürece kod bloğunu tekrar çalıştırma
* **Karşılaştırma Operatörü (`!=`):** Kullanıcının tahminini gizli sayıyla karşılaştırma
* **Kullanıcı Girdisi ve Tip Dönüşümü:** `input()` ve `int()` fonksiyonları ile tam sayı alma
* **Çok Satırlı Çıktı:** Üç tırnak (`"""`) kullanarak karşılama ekranı yazdırma

## Çalıştırma

1. Bilgisayarınızda **Python 3** yüklü olduğundan emin olun.
2. Terminali açarak dosyanın bulunduğu klasöre gidin.
3. Aşağıdaki komutu çalıştırın (dosya adını kendi dosyanıza göre güncelleyin):

```bash
python dosya_adi.py
